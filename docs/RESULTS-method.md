## Direction Audit — 2026-07-18

The current direction is only partly correct. The [Schema report](https://schema-harness.github.io/) does not claim that architectural minimalism is the result. It attributes the controlled Claude gain to three enforced constraints—an executable transition program, whole-history validation before planning, and surprise-gated execution—then emphasizes that every exploratory action is scored, the excess-action penalty is squared, and Fable's advantage under the same harness came from earlier representational revisions and better discriminating experiments. Coverage limits how many games this project has measured; it cannot explain a 100-action first-level failure. The report's own summary separates the harness's cost of *using* a theory from the model's cost of *discovering* one.

The BP35 result proves narrower fidelity than “the blog's machine is proven.” Replaying one released trajectory with 566/566 byte-identical grids and the same 93.51% score establishes on-trajectory compatibility of state reconstruction, model loading, prediction comparison, event recording, and scoring. It does not establish off-trajectory tool behavior, hidden system context, compaction/session behavior, or generative policy equivalence. The live CD82 stream exposes one unresolved boundary: Luna committed at `5/6` and `22/23` replay in early turns. The report requires whole-history validation before *planning*, so exploratory probes may be outside that claim, but the local harness does not mechanically enforce green history before every action. Fixed-trace parity cannot decide that distinction.

[OPINE-World](https://arxiv.org/abs/2607.01531) reinforces the pre-clear policy diagnosis but does not identify a remedy causally. It uses a goal-directed actor before reward, synthesizes a goal predicate and invokes its planner only after the first level clear, and took 74 actions on CD82 level 0 before finishing later levels in `6/20/23/20/17`. Its 78.4% result changes both architecture and base model relative to its strongest baseline, uses one run per game, and reports no component ablations. Actor/synthesizer separation, a critic, and ontology error are therefore hypotheses, not demonstrated gains. The transferable observation is narrower: before the first reward, maintain and test goal, affordance, representation, and resource hypotheses; do not force an unsupported executable goal predicate.
